# Learn the Basics
``A follow-up repository with notes and extra exploration :)``

**Authors**: Suraj Subramanian, Seth Juarez, Cassie Breviu, Dmitry Soshnikov, Ari Bornstein.

Most machine learning workflows involve working with data, creating models, optimizing model parameters, and saving the trained models. This notebook introduces a complete ML workflow implemented in PyTorch.

**Datasets used**: FashionMNIST.
**Datasets purpose**: to train a neural network that predicts if an input image belongs to one of the following classes: T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, or Ankle boot.

## myEnv

* miniConda with python-3.9
* Cuda-11.6
* Pytorch compatible with 11.6.
* with GPU (NVIDIA GeForce RTX 3060 Laptop GPU - 6 gb)
* Core i7.
